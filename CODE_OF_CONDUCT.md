# Code of Conduct

This repository adopts a simple standard:

- Be direct and respectful.
- Focus on reproducible behavior, not personal blame.
- Report privacy or security concerns privately as described in [SECURITY.md](SECURITY.md).
- Keep public examples sanitized. Do not open issues or pull requests that contain real tokens, emails, project IDs, or machine-specific paths.

Maintainers may remove content that exposes private data or creates unnecessary risk for other users.
